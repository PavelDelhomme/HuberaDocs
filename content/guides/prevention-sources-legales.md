# Prévention : sources légales vs copies non autorisées

Page destinée aux élèves / équipe Hubera. **Ce n’est pas un mode d’emploi** pour récupérer des films ou de la musique hors licence.

## Ce qu’il faut retenir

- Une œuvre (film, musique, série) appartient à ses **ayants droit**. La copier, la télécharger ou la redistribuer **sans accord** est illégal dans la plupart des pays, y compris la France (CPI).
- Un lien « torrent », un magnet, un dump « gratuit HD » ou un compte « DeviantArt / mega / drive random » **n’est pas** une source Hubera. On ne les intègre pas, on ne les documente pas comme pipeline technique.
- **Hubera Stream** ne catalogue que des sources **officielles** (ex. Pluto TV, Arte.tv) via leurs API / flux et leurs conditions d’utilisation.
- **Hubera Music** hors-ligne = titres **déjà** dans la bibliothèque Hubera (fichiers que le service a le droit de servir), pas des dumps externes.

## Comment faire correctement

1. Utiliser les **plateformes sous licence** : Arte.tv, Pluto TV, chaînes / VOD officielles, YouTube du ayant droit, services d’abonnement légaux.
2. Pour un projet pédagogique : demander une **autorisation écrite**, ou s’appuyer sur des œuvres **libres de droits** / licences Creative Commons **compatibles** avec l’usage (lire la licence : NC, ND, SA).
3. Citer la source. Ne pas extraire un flux DRM ni contourner une protection (c’est un délit distinct).

## Comment signaler un abus (voies publiques)

Sans « infiltrer » un réseau pirate :

- Formulaire **signalement** de l’hébergeur (Google, Cloudflare, l’hébergeur du site) quand il en propose un.
- En France : [Pharos](https://www.internet-signalement.gouv.fr/) pour contenus illicites ; ayants droit / Hadopi-Arcom pour la contrefaçon massive.
- Contacter l’**éditeur / le producteur** via le site officiel de l’œuvre.

Ne jamais télécharger « pour vérifier » un catalogue pirate : la constatation se fait par URL / capture du site, pas par récupération du fichier.

## Ce que Hubera refuse dans le produit

- Torrents, magnets, scrapers de dumps, miroirs « films gratuits »
- Contournement DRM
- Toute UI qui oriente vers ces sources
