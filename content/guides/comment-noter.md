# Comment noter (Paul)

Tout se passe **ici**, dans Hubera Docs (`docs.hubera.cloud`), pas dans Hubera Admin.

1. **Noter** : ce qui ne va pas / à améliorer / à faire — une app dans le menu. Ça crée une tâche kanban priorité 1.
2. **Tâches** : avancer une carte, ajouter du texte.
3. **PDF** : les mails de l’agent (6 oct + jours précédents).
4. **Docs** : fichiers `.md` de ce dépôt.

Bitwarden : ajoute l’URI `https://docs.hubera.cloud` sur la fiche Hubera ID déjà enregistrée (autofill). Pas Hubera Admin.

Hubera Admin = tenants Cloudity / console `/4dm1n`. Pas le cockpit projet.
